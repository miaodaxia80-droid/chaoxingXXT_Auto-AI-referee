# 功能覆盖清单

最后核对：2026-08-12

本清单是新 FastAPI + Vue 应用相对旧实现的交付边界。只有在行为已经实现、有自动化覆盖，并且适用时能从新 UI 使用，项目才标记为 `[x]`。`[ ]` 表示明确未完成或尚未达到该验收标准，不代表核心链路不可用。

## 账号与访问控制

- [x] 首次管理员设置、登录、退出、会话过期和登录失败限流。
- [x] HttpOnly 会话、CSRF token、同源/允许 Origin 校验，且读取接口不返回秘密。
- [x] 超星账号新增、编辑、启用、停用、删除和有界 UTF-8 CSV 导入。
- [x] 密码/Cookie 登录、Cookie 失效回退和刷新 Cookie 加密持久化。
- [x] 账号备注、User-Agent、倍速、章节并发和未开放章节策略。
- [x] 每个账号运行时和每个并发章节拥有隔离的 HTTP Session，并在结束时关闭。

## 课程与学习任务

- [x] 从 UI 按账号读取/刷新课程、搜索课程并读取选中课程的章节。
- [x] 对单个课程全选章节、仅选未完成章节或逐章选择。
- [x] 多课程同时勾选，逐门读取章节，并为每门课程的未完成章节批量创建任务；逐项报告跳过/失败。
- [x] 视频、音频、文档、测验、阅读和空页面任务点。
- [x] 课程任务和章节结果持久化，并通过结构化事件展示进度。
- [x] 同账号互斥、可配置多账号 worker 容量和账号内有界章节并发。
- [x] 单任务持久化暂停、恢复、取消，以及全局 worker 启停。
- [x] 队列多选暂停/恢复/取消、终态任务批量删除和全部终态历史清理；活动任务有意禁止直接删除。
- [x] 运行时间窗、安全点暂停、相同任务恢复、租约过期和子进程崩溃恢复。
- [x] SQLite partial unique index 与 API 409 共同阻止同账号/课程的重复活跃任务。

## 答案能力

- [x] Yanxi、Like、TikuAdapter、OpenAI-compatible 和 SiliconFlow provider。
- [x] 自动、仅保存和提交模式，以及显式覆盖率阈值。
- [x] 可跨线程/进程使用的 SQLite 答案缓存和 TTL；课程上下文参与缓存隔离。
- [x] 多模型并行回答、共识/referee 选择和有界并发。
- [x] 课程上下文注入和受限 DuckDuckGo 搜索增强；搜索失败只降级，不中断答题。
- [x] Provider 能力约束、URL/响应边界和网络 Session 关闭。
- [x] 全局答案配置、账号继承/覆盖，以及任务排队时的配置快照。
- [x] 全局和账号级答案配置均可从 UI 编辑并往返保存。

## 可观测性与运维

- [x] 概览页账号数、运行任务、今日完成、服务健康与当前任务进度。
- [x] 全局/任务事件查询和支持 `Last-Event-ID` 的可重连 SSE；前端自动重连。
- [x] 章节成功、失败、未提交、未开放、未知任务点等结果在任务与活动页可见。
- [x] 独立人工接管队列、单项/批量标记已处理，以及不改写原章节结果的管理员审计记录。
- [x] ServerChan、Qmsg、Bark 和 Telegram 设置，以及任务终态 outbox 重试投递。
- [x] 可配置事件保留周期、自动归档后再保留一个周期、批量归档 API 和最终清理。
- [x] 在 UI 中按截止日期手动发起事件归档，并明确归档与最终删除的区别。
- [x] CPU、内存、可用时的温度，以及进程容量、心跳、租约和过期运行等 worker 健康指标。
- [x] 浏览器本地保存的深色/浅色/跟随系统主题，以及 reduced-motion/transparency 适配。

## 交付与数据安全

- [x] Windows 开发/生产启动命令和 `serve`、`backup`、`restore` 运维 CLI。
- [x] 多阶段 `Dockerfile`、Compose 持久化数据卷、健康检查和优雅停止配置。
- [ ] 在本次开发机完成实际 Docker 镜像构建；该机器没有 Docker CLI。
- [x] CI 中定义 `linux/amd64` 和 `linux/arm64` 的 Buildx、迁移和健康检查矩阵。
- [x] Alembic 版本化迁移链及空库 `upgrade` / `check` / `downgrade` 往返验证。
- [x] SQLite snapshot 备份、数据库与 `master.key` 配对校验、离线强制恢复、回滚目录和阶段 journal。
- [x] 后端 `uv.lock` 与前端 `pnpm-lock.yaml` 锁定依赖并供容器/CI 使用。
- [x] 后端单元、API 集成、数据库并发、协议 fixture 和安全回归测试。
- [x] Playwright Chromium E2E，覆盖初始化、登录、主要路由、390x844 溢出和主题持久化/跟随系统，并接入 CI。
- [x] 默认 dry-run、显式 `--apply` 的旧 Flask SQLite 一次性 importer；只读源库，导入受支持账号字段和调度设置，不导入任务/事件/集成配置，且 `use_cookies=false` 时不导入残留 Cookie。

## 结论

新应用的核心路径和本轮目标 parity 已覆盖：管理员初始化 -> 账号录入/受限 legacy 导入 -> 多课程/章节发现 -> 单项或批量排队 -> 独立 worker 执行与批量控制 -> 答案和通知 -> 结构化事件/人工接管 -> 备份恢复。当前未勾选项仅表示本开发机没有 Docker CLI，尚未在本机实际构建镜像；应以 CI 或目标部署机的容器验证补齐，不能据此声称本地 Docker 构建成功。
